# Job Search Agent

Локальный помощник для поиска работы: сохранение вакансий, разбор требований, выбор подходящего резюме, черновики откликов, проверка текста перед отправкой и контроль follow-up.

## Статус

Сейчас проект находится на базовом CLI-этапе: всё работает локально через Python и SQLite. План и аудит исходных материалов лежат в `docs/audit_and_plan.md`.

## Стек

- Python 3.11+
- Локальный клиент в терминале
- SQLite-база в `data/job_agent.sqlite`
- Позже: Telegram-бот, синхронизация с Google Sheets, LLM-адаптер
- Любая отправка только после ручного одобрения

## Запуск

Из папки проекта:

```powershell
cd путь\к\job-search-agent
.\agent.cmd
```

Клиент покажет меню. Можно вводить номер пункта, команды помнить необязательно.

## Локальная настройка

Публичный репозиторий не содержит личную базу, черновики, резюме и приватный профиль. Для локальной работы скопируйте пример профиля:

```powershell
Copy-Item data\profile.example.yaml data\profile.yaml
```

После этого отредактируйте `data/profile.yaml` под себя. Этот файл игнорируется Git.

## Главное меню

```text
1  Быстрый сценарий из буфера
2  Добавить вакансию из буфера обмена
3  Вставить вакансию вручную
4  Показать вакансии
5  Показать отклики
6  Открыть карточку вакансии
7  Открыть карточку отклика
8  Объяснить анализ вакансии
9  Создать черновик отклика
10 Пересоздать черновик отклика
11 Открыть черновик в редакторе
12 Импортировать отредактированный текст
13 Проверить отклик перед отправкой

```

## Самый простой сценарий

```text
1
```

Перед этим скопируйте полный текст вакансии. Агент сам возьмёт текст из буфера обмена, сохранит вакансию, создаст черновик, предложит открыть его для редактирования, импортировать финальный текст, проверить, одобрить и отметить отправку.

Если такая вакансия уже есть в базе, агент не создаст дубль. Он покажет существующую карточку и её ID.

После добавления вакансии агент сразу показывает рабочую карточку:

```text
Карточка вакансии #23
Название:
Компания:
Формат:
Зарплата:
Направление:
Резюме:
Шанс:
Решение:
Почему:
Что подчеркнуть:
Риски:
Вопрос работодателю:
Команды дальше:
  draft 23
  explain 23
  status 23 skipped
```

## Ручной сценарий

```text
3
[вставить полный текст вакансии]
///
```

Если пункту нужен ID вакансии или отклика, клиент сам его спросит.

## Канал отклика

Когда агент спрашивает, куда отправили отклик, можно выбрать цифру:

```text
1  HH.ru
2  Telegram
3  Email
4  LinkedIn
5  Форма на сайте
6  Фриланс-биржа
7  Вручную / другое
```

Если не важно, просто нажмите Enter: сохранится `вручную / другое`.

## Формат вакансии

Можно вставлять вакансию как есть, без шаблона:

```text
Название вакансии
Зарплата
Опыт
Формат работы

Описание задач
Требования
Условия
Ключевые навыки
```

Если есть ссылка, лучше добавить её в начало или конец текста.

## Профиль кандидата

Профиль хранится здесь:

```text
data/profile.yaml
```

Черновики и проверка используют его, чтобы честно учитывать опыт, английский, формат работы и зарплатные ожидания.
